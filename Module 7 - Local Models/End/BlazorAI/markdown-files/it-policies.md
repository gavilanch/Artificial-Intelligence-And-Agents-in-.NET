# Advanced IT Policies

---

## 1. System Access

- Access is granted according to the **principle of least privilege**.
- Access requests must be approved by the department leader.

---

## 2. Software Requests

- A ticket must be created to request additional software.
- IT will validate licenses and compatibility.

---

## 3. Data Backup

- Employees must save their work in corporate systems.
- Storing critical information on personal devices is not allowed.

---

## 4. Use of Personal Devices

- It is allowed under the BYOD model with restrictions.
- Devices must comply with security policies (antivirus, encryption, etc.).

---

## 5. Security Incidents

- All incidents must be reported immediately.
- IT will initiate an analysis and mitigation process.
